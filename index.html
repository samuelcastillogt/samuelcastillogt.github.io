Sobre mí

Soy desarrollador web Full Stack en Guatemala. Me especializo en el ecosistema JavaScript (React, Next.js, React Native y Node.js) y también trabajo con C# y .NET cuando el proyecto lo requiere.

He trabajado en equipos ágiles con Scrum y Kanban, principalmente como desarrollador Frontend, pero también diseñando APIs, modelando bases de datos relacionales y no relacionales y automatizando procesos con cronjobs en Kubernetes.

Tengo el certificado profesional de Google UX Design, así que además de código aporto criterio de diseño: interfaces accesibles, centradas en el usuario y pensadas para convertir.

  • Frontend con enfoque en productoInterfaces en React y React Native con buen rendimiento, accesibilidad y SEO técnico.
  • Backend y microserviciosAPIs con Node.js, Express y NestJS, colas de reintento y capas de fiabilidad.
  • Sistemas empresarialesIntegración de SAP con sistemas legacy y bases de datos Oracle, SQL Server y PostgreSQL.
  • Diseño UXInvestigación, wireframes y prototipos en Figma antes de escribir la primera línea de código.
